Sections and periodic orbits

Cut a flow with a plane and watch where orbits come back to it: the flow becomes a map, and a periodic orbit becomes a fixed point. Because the return map and its derivative are enclosed, the fixed point can be proven to exist. That turns a closed curve on a screen into a theorem.

const V = vanDerPol(1);
const section = { variable: "y", value: 0, direction: -1 };      // y = 0, crossed with y decreasing
V.returnMap(section, { x: 2 });               // { point: [2.0086122778…], time: 6.65156…, derivative: [[0.00089996…]] }
const orbit = V.periodicOrbit(section, { x: 2 });
orbit.proven;                                 // true
orbit.period;                                 // 6.66328685932…, an interval 10⁻¹² wide
orbit.stability;                              // "attracting"

lorenz().periodicOrbit({ variable: "z", value: 27 }, { x: -13.76, y: -19.58 }, { returns: 2 });
// proven: a saddle orbit of period 1.558652210…, expanding by 4.7129 each time round

The return map

A section is a plane \(\{x_j = v\}\) with a direction of crossing: { variable: "z", value: 27, direction: 1 } means the plane \(z = 27\) crossed with \(z\) increasing. Its points are named by the other variables. The first-return map \(P\) sends a point of the section to the next point where its orbit crosses the section in the same direction.

returnMap(section, start) follows a point, or a box of points given as intervals, and returns enclosures of \(P\), of the time taken, and of the derivative \(DP\) in the section's coordinates. On the way the solver watches every step for crossings: a step whose rough box meets the plane must have the field pointing strictly through it, so each crossing is counted once and in the right direction; if the field might be tangent to the section there, the call stops and says so. At the crossing itself each point of the set is moved along the field onto the plane, which gives

\[ DP = \Bigl(I - \frac{f\,e_j^{\mathsf T}}{f_j}\Bigr) D\varphi_\tau , \]

the derivative of the flow with the direction of the flow projected out. returns: k gives the \(k\)-th return.

Proving a periodic orbit

A periodic orbit crosses the section at a fixed point of \(P\) (or of \(P^k\)). periodicOrbit(section, guess) first improves the guess by Newton's method on \(P(x) - x\), using the enclosed return map as a very accurate numerical one. Then it takes a small box \(X\) round the candidate \(m\) and applies Krawczyk's test to \(G(x) = P(x) - x\):

\[ K(X) = m - C\,G(m) + \bigl(I - C\,(DP(X) - I)\bigr)(X - m) \subset \operatorname{int} X . \]

When the inclusion holds, \(P\) has exactly one fixed point in \(X\): a periodic orbit exists, it crosses the section inside the box returned as point, and no other periodic orbit of that many returns crosses within radius of it. The test needs \(DP - I\) to be invertible, so it works for attracting, repelling and saddle orbits alike; it does not work at an orbit with a multiplier equal to 1, and there the result has proven: false and a reason.

The eigenvalues of \(DP\) at the fixed point are the orbit's multipliers (Floquet multipliers): all inside the unit circle for an attracting cycle, on both sides for a saddle.

Three orbits

Van der Pol. The limit cycle for \(\mu = 1\) crosses \(y = 0\) at \(x = 2.00861986087\ldots\) with period \(6.66328685932\ldots\), and the return map contracts by the factor 0.00086 there: after one turn a nearby orbit is a thousand times closer.

Rössler. For \(c = 2.5\) the attractor is a single cycle, proven attracting. For the classical \(c = 5.7\) the attractor is chaotic, and the orbit that turns once is still there inside it, as a saddle with multiplier \(-2.40\): the minus sign says that the band it lives on is twisted like a Möbius strip.

Lorenz. The attractor contains infinitely many periodic orbits, all of them saddles, and none can be found by waiting for an orbit to settle. The shortest winds once round each wing. It crosses \(z = 27\) upward twice per period, so it is a fixed point of the second return: { returns: 2 }. Its period, \(1.5586522107\ldots\), agrees with the value computed by Viswanath to many more digits, and here it is the period of an orbit that provably exists.
