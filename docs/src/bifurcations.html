Period doubling and windows

As the parameter of a family moves, attracting cycles appear, double and vanish. The parameters at which that happens are solutions of equations, and here each is proven to exist inside a tiny interval.

const family = logistic();    // r is the parameter
bifurcationPoint(family, { parameter: "r", period: 1, near: [2.9, 0.6] });   // r = 3
periodDoubling(family, { parameter: "r", levels: 5, start: [2.9, 0.6] });    // 3, 3.449…, 3.544…, …
periodicWindow(family, { parameter: "r", period: 3, near: [3.835, 0.5] });   // born at 1 + √8
superstable(family, { parameter: "r", period: 2, range: [3, "7/2"] });       // 1 + √5
bifurcationDiagram(family, { parameter: "r", range: [2.8, 4], count: 400 }); // data for the picture (estimated)

The two equations

A cycle of period n is a solution of \(g(x, r) = x\) with \(g = f_r^n\). It changes its nature when its multiplier \(g_x(x, r)\) passes through ±1:

  • −1: period doubling. In the generic case the cycle stops attracting and an attracting cycle of period 2n splits off from it. That needs the multiplier to cross −1 with nonzero speed as r changes and a nonzero Schwarzian derivative of \(g\) at the point; its sign decides whether the new cycle is attracting (supercritical, as in the logistic family) or a repelling one shrinks onto the old cycle (subcritical).
  • +1: tangent (saddle-node) bifurcation, in the generic case. A pair of cycles, one attracting and one repelling, appears out of nothing. This is how a periodic window opens in the middle of the chaotic range. It takes \(g_{xx} \ne 0\) and \(g_r \ne 0\) at the point; a multiplier of +1 alone also occurs in transcritical bifurcations (two cycles cross and exchange stability, as at r = 1 for the logistic map) and pitchforks (one cycle splits into three, where a symmetry forces \(g_{xx} = 0\)).

The functions on this page find and prove where the multiplier equals ±1; which scenario happens there is decided by those extra conditions, which the logistic family meets at the parameters shown.

So a bifurcation is a solution (x, r) of two equations in two unknowns,

\[ g(x, r) - x = 0, \qquad g_x(x, r) = \pm 1 . \]

bifurcationPoint solves them in two stages. Newton's method in doubles finds an approximate solution near the point you give. Then Krawczyk's test is run in exact interval arithmetic on a small box B around it: if the interval Newton image K(B) lies strictly inside B, there is exactly one solution in B. That is a proof, and the box is then contracted until the parameter is known to the digits asked for. The derivatives of \(f^n\) that the test needs come from the chain rule, carried through the n steps alongside the orbit.

The cascade

periodDoubling follows the attracting cycle from one doubling to the next and proves each: for the logistic family \(r_1 = 3\), \(r_2 = 1 + \sqrt6\), \(r_3 = 3.544090\ldots\), and so on. The gaps shrink by a factor that approaches Feigenbaum's constant δ = 4.669201609…, the same for every family with a quadratic maximum. The parameters are certified, and so is each ratio \((r_k - r_{k-1})/(r_{k+1} - r_k)\) as a quotient of intervals. That the ratios converge to δ is a theorem with a long computer-assisted proof, and it is not proven by this function, which says so in its kind.

Windows and superstable cycles

periodicWindow returns the birth (multiplier +1) and the first doubling (multiplier −1) of an attracting cycle of the given period, both proven, and the parameter between them at which the cycle is superstable: it passes through the critical point, so its multiplier is 0. The period-3 window of the logistic family opens at \(1 + \sqrt8 = 3.828427\ldots\) and its 3-cycle doubles at 3.841499…. By Sharkovskii's theorem, from that parameter on there are cycles of every period.

superstable finds every parameter in a range at which the critical point has period n. That is one equation in one unknown, \(f_r^n(c) = c\), solved by the certified zero finder.

The diagram

bifurcationDiagram gives the data for the familiar picture: for each parameter, the points an orbit visits after a transient. It is computed in doubles and labelled kind: "estimated". It is a good picture, since the attractor a float orbit settles on is the right one even though the orbit is not, but it proves nothing, and it shows a cycle of high period and chaos identically.
