Reference

Everything in the library

Every export of @ratmath/chaos, with what it takes and what it returns. Numbers go in as whole numbers, fractions or decimal strings; a JavaScript number that is not whole is refused where an exact value is meant.

Maps

ExportWhat it does
map(formula, { variable, params, critical })A map of the line from a formula in analytic's notation. Returns an IteratedMap.
logistic(r = 4), tent(mu = 2), quadratic(c = -2)The standard families \(rx(1 - x)\), \(\mu(\tfrac12 - |x - \tfrac12|)\) and \(x^2 + c\).
doubling(x0, { base })\(x \mapsto 2x \bmod 1\) on a rational, exactly: { orbit, preperiod, period, cycle, floatReachesZeroAt }.
IteratedMapThe class. Fields: text, variable, params, polynomial (coefficients, or null), tree.

Methods of a map

MethodWhat it does
at(x), enclose(X, bits), float(x), derivativeAt(x)One step: exact, as an interval, in doubles; and f′.
orbit(x0, n, { maxBits })The true orbit in rationals. See Orbits.
enclosedOrbit(x0, n, { digits, bits })The true orbit as intervals: { terms, bits, width }.
floatOrbit(x0, n), cobweb(x0, n)The orbit in doubles; the corner points of a cobweb diagram.
compare(x0, n, { digits })Float beside true: { rows, parted }.
fixedPoints(), periodicPoints(n)Exact points of least period n with multiplier and stability. See Periodic points.
cycles(n)The points grouped into cycles, each with its multiplier and Lyapunov exponent.
periodicPointsIn(n, [a, b], { digits })Certified periodic points of any formula.
iterate(n), criticalPoints([a, b]), with(params)\(f^n\) as coefficients; zeros of f′; the family at other parameters.

Exponents, bifurcations, symbols

ExportWhat it does
lyapunov(f, x0, { steps, transient, digits })The average of log|f′| along the true orbit, enclosed. See Lyapunov exponents.
sensitivity(f, x0, delta, { steps, threshold })The separation of two true orbits, step by step.
bifurcationPoint(family, { parameter, period, multiplier, near, digits })A parameter where a cycle's multiplier is ±1, proven. See Bifurcations.
periodDoubling(family, { parameter, levels, start })The cascade, each doubling proven, and the ratios of the gaps.
periodicWindow(family, { parameter, period, near })Birth, superstable parameter and first doubling of a window.
superstable(family, { parameter, period, range, critical })Parameters where the critical point has the given period.
bifurcationDiagram(family, { parameter, range, count, transient, keep })Data for the picture, in doubles, marked estimated.
itinerary(f, x0, n), kneading(f, n)Symbol strings on true orbits. See Symbolic dynamics.
sharkovskii{ order(limit), compare(a, b), forces(a, b), forced(n, limit) }.
ChaosErrorWhat the library throws, with a code: inexact, too-large, escapes, not-polynomial, not-proven and others.
planThe phases still to come, each { phase, contents, estimate }.
