Flows, enclosed

A flow is the motion defined by a system of differential equations x′=f(x)x' = f(x)x′=f(x). On a chaotic flow a numerical solver drifts off the true solution like a float orbit does, only more quietly. Here the solution is enclosed: boxes that are proven to contain it, for a point or for a whole box of starting points.

const L = lorenz();                            // x′ = 10(y − x), y′ = x(28 − z) − y, z′ = xy − (8/3)z
const s = L.solve([1, 1, 1], 20);
s.final;                                       // three intervals, each about 10⁻⁶ wide, that hold x(20), y(20), z(20)
s.at("7/2");                                   // the same at any earlier time
L.floatOrbit([1, 1, 1], 20, { steps: 2000 });  // Runge–Kutta: ends at 13.47…, but the true x(20) is 13.7931…
flow(["y", "-x - y^3"], { variables: ["x", "y"] });   // any formulas

The systems

  • lorenz(s, r, b): x′=s(y−x), y′=x(r−z)−y, z′=xy−bzx' = s(y - x),\ y' = x(r - z) - y,\ z' = xy - bzx′=s(y−x), y′=x(r−z)−y, z′=xy−bz, by default 10, 28, 8/3: Lorenz's model of convection and the first strange attractor.
  • rossler(a, b, c): x′=−y−z, y′=x+ay, z′=b+z(x−c)x' = -y - z,\ y' = x + ay,\ z' = b + z(x - c)x′=−y−z, y′=x+ay, z′=b+z(x−c): one nonlinear term, and a band that folds once.
  • vanDerPol(mu): x′=y, y′=μ(1−x2)y−xx' = y,\ y' = \mu(1 - x^2)y - xx′=y, y′=μ(1−x2)y−x: an oscillator that settles on one limit cycle whatever the start.
  • pendulum(c): x′=y, y′=−sin⁡x−cyx' = y,\ y' = -\sin x - cyx′=y, y′=−sinx−cy.
  • flow(formulas, { variables, params }) for anything else built from + − × ÷, whole powers, sin and cos. Parameters are exact numbers, and with({ r: 24 }) gives the same family at other values.

How the solution is enclosed

The solver takes steps. In one step of length hhh from a set of points:

  1. A rough box. A box RRR with X+[0,h] f(R)⊆RX + [0, h]\,f(R) \subseteq RX+[0,h]f(R)⊆R contains the solution on the whole step, by the Picard–Lindelöf theorem.
  2. A Taylor polynomial with a bounded remainder. The Taylor coefficients of the solution are computed from the formulas by automatic differentiation, in interval arithmetic. The polynomial of degree 12 from the centre of the set is the main part; the next coefficient, taken over all of RRR, bounds what was left out.
  3. The derivative of the flow. The same is done for the variational equation V′=Df(x) VV' = Df(x)\,VV′=Df(x)V, which gives an interval matrix AAA containing the derivative of the time-hhh map at every point of the set. By the mean value theorem the image of the set lies in (image of the centre) + AAA·(set − centre).
  4. Sets that turn. A set is kept as a centre, a frame and a box of coordinates in that frame, and the new frame is the orthogonal factor of AAA times the old one (Lohner's method). A box with fixed axes would be re-wrapped at every step and grow even on a rigid rotation; a frame that turns with the flow does not.

All arithmetic is in doubles rounded outward, so the bounds are bounds, and since a double is an exact rational the results are handed back as RationalIntervals. The sine and cosine come from their own series with the remainder bounded, not from the platform's.

What it shows on a chaotic flow

From (1,1,1)(1, 1, 1)(1,1,1) the Lorenz solution is enclosed to within 10−910^{-9}10−9 at t=10t = 10t=10, 10−610^{-6}10−6 at t=20t = 20t=20 and 0.040.040.04 at t=30t = 30t=30: the enclosure widens at the rate the flow separates orbits (the Lyapunov exponent is about 0.9, so a factor of e9≈8000e^{9} \approx 8000e9≈8000 per ten time units), because rounding errors are perturbations too and the enclosure has to hold them all. That widening is the honest part. A Runge–Kutta solver with 2000 steps returns x(20)=13.47x(20) = 13.47x(20)=13.47 with nothing to say that only the first two digits are right; the enclosure shows 13.793113.793113.7931.

The same widening limits how far a set can be followed. A box of starting points of width www picks up an error of order w2w^2w2 per step from the curvature of the flow, so thin sets go far and wide ones do not. When no enclosure can be found the solver stops and says where: complete is false, reached is the time it got to, and reason says why. A solution that blows up in finite time, such as x′=x2x' = x^2x′=x2 from 1, ends that way just before t=1t = 1t=1.

For a single orbit to many digits there is also analytic's ode.solve, which works in exact rational arithmetic with Taylor models. It is some hundred times slower, and it is what to use when 15 digits are not enough.
