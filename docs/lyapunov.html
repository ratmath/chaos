Lyapunov exponents and sensitivity

Two orbits that start a distance δ apart are, after n steps, about δ eλn\delta\,e^{\lambda n}δeλn apart. The number λ is the Lyapunov exponent, and a positive one is what "chaotic" means in practice.

lyapunov(logistic(4), "1/10", { steps: 300 });           // { value, float, bits, kind }
lyapunov(logistic("3.2"), "1/10", { steps: 200, transient: 100 });
sensitivity(logistic(4), "1/10", "1/1000000000000");     // { rows, reaches, rate, factor }

The definition

The distance between nearby orbits is multiplied at each step by about ∣f′(xi)∣|f'(x_i)|∣f′(xi​)∣, so

λ=lim⁡n→∞1n∑i=0n−1log⁡∣f′(xi)∣. \lambda = \lim_{n\to\infty} \frac1n \sum_{i=0}^{n-1} \log\bigl|f'(x_i)\bigr| . λ=n→∞lim​n1​i=0∑n−1​log​f′(xi​)​.

lyapunov computes the average over steps terms (after discarding transient). What makes it different from the usual program is that the xix_ixi​ are the true orbit, enclosed with enough digits, and the logarithms are enclosed too, so the result is an interval that contains the finite-time average of the orbit you asked about. Its kind says so: certified for n steps. The limit itself is not something a finite computation proves, and for a chaotic orbit the average settles slowly as n grows.

The field float is the same average computed the ordinary way. For a chaotic orbit it differs from the certified one in the second or third decimal, because after fifty steps the program is averaging along a different orbit. Both are near the right answer for the same reason: almost every orbit gives the same limit.

Where the value is known

  • For an attracting cycle, λ is 1nlog⁡∣multiplier∣\tfrac1n\log|\text{multiplier}|n1​log∣multiplier∣, negative, and cycles gives it directly. An orbit attracted to the cycle has the same exponent.
  • For the tent map with slope 2, ∣f′∣=2|f'| = 2∣f′∣=2 everywhere, so λ = ln 2 on every orbit.
  • For the logistic map with r = 4, the change of variable x=sin⁡2(πθ/2)x = \sin^2(\pi\theta/2)x=sin2(πθ/2) turns it into the tent map, so λ = ln 2 for almost every starting point. Every periodic orbit except the fixed point 0 also has exactly ln 2 per step, as the 3-cycles on the previous page show.

Sensitive dependence, measured

sensitivity(f, x0, δ) follows the true orbits of x0x_0x0​ and x0+δx_0 + \deltax0​+δ together and returns their separation at each step as an enclosure, the first step at which it passes a threshold (1/10 by default), and the average growth factor per step up to then. For r = 4 the factor is about 2: a starting error of 10−1210^{-12}10−12 is a visible error after about 36 steps, and no instrument or data type changes that count by much, since each extra decimal digit of accuracy buys only log⁡210≈3.3\log_2 10 \approx 3.3log2​10≈3.3 more steps.
