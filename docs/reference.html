Reference

Everything in the library

Every export of @ratmath/chaos, with what it takes and what it returns. Numbers go in as whole numbers, fractions or decimal strings; a JavaScript number that is not whole is refused where an exact value is meant.

Exponents, bifurcations, symbols

lyapunovExponent(f, { distribution, interval, digits }), invariantDensity(f)The exponent of almost every orbit as a certified integral of log|f′| against the invariant measure. See Lyapunov exponents.
sensitivity(f, x0, delta, { steps, threshold })The separation of two true orbits, step by step.
bifurcationPoint(family, { parameter, period, multiplier, near, digits })A parameter where a cycle's multiplier is ±1, proven. See Bifurcations.
periodDoubling(family, { parameter, levels, start })The cascade, each doubling proven, and the ratios of the gaps.
periodicWindow(family, { parameter, period, near })Birth, superstable parameter and first doubling of a window.

bifurcationDiagram(family, { parameter, range, count, transient, keep })Data for the picture, in doubles, marked estimated.

sharkovskii{ order(limit), compare(a, b), forces(a, b), forced(n, limit) }.

Maps of the plane

ExportWhat it does
planeMap([f, g], { variables, params }), henon(a, b), standardMap(k), PlaneMapA map of the plane from two formulas. Fields: text, variables, params, determinant (when constant), areaPreserving. See Maps of the plane.
at(p), float(p), enclose(P, bits), jacobian()One step: exact, in doubles, as intervals; the Jacobian as formulas.
orbit, floatOrbit, enclosedOrbit, compareAs for maps of the line, on pairs.
periodicPoints(n, region, { all }), fixedPoints(region), cycles(n, region)Every point of least period n in a box, each proven and alone in its enclosure, with multipliers and stability; complete says none was missed.
exactPeriodicPoints(n)The points as algebraic numbers, when one coordinate can be eliminated.
lyapunov(p, n)Both exponents, estimated; their sum enclosed when the determinant is constant.
catMap(), torusMap(matrix), TorusMapInteger matrices on the torus, exact: at, orbit, period, periods(q), fixedPointCount(n), eigen(), entropy(), floatPartsAt. See The cat map and the horseshoe.
horseshoe(), HorseshoeSmale's horseshoe in exact coordinates: at, itinerary, periodicPoint(word), periodicPoints(n), orbitCount(n), strips(n), dimension.

Flows

ExportWhat it does

lorenz(s, r, b), rossler(a, b, c), vanDerPol(mu), pendulum(damping)The standard systems.
solve(p0, until, { order, maxStep, maxSteps })The solution through a point or a box, enclosed: { final, complete, reason, reached, steps, width, at(t) }. See Flows.
floatOrbit(p0, until, { steps })A path in doubles for drawing: { t, points }.
returnMap(section, start, { returns })The return map of a section { variable, value, direction }: enclosures of the point, the time and the derivative. See Sections and periodic orbits.
periodicOrbit(section, guess, { returns, radius })A periodic orbit proven to exist near the guess, with period, multipliers and stability; or { proven: false, reason }.
equilibria(region)Every equilibrium in a box, with eigenvalues and kind. See Equilibria.
bifurcations(param, [from, to], region, { samples, tol })Parameter brackets where equilibria appear, merge or change stability, named.
