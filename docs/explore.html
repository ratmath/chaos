A map and an orbit

Use r as the parameter in the formula. Exact inputs only: 3.2 means 16/5. Try r = 3.2 (a 2-cycle), 3.5 (a 4-cycle), 3.83 (the period-3 window) and 4.

Periodic points

For a polynomial map these are exact algebraic numbers. The Lyapunov exponent in the first panel is the certified average along the true orbit.

A map of the plane

The Hénon map (x,y)↦(1−ax2+y, bx)(x, y) \mapsto (1 - ax^2 + y,\ bx)(x,y)↦(1−ax2+y, bx). The dots are a floating-point orbit, an estimate of the attractor. The marked points are the points of the chosen least period in the square from −2 to 2, each proven to exist and to be alone in its box. Try a = 1, b = 0.3, where a cycle of period 4 attracts.

A flow

The curve is a path in doubles, for the eye. The table is proven: every equilibrium in the box shown, with its kind read from enclosed eigenvalues.

Escape-time pictures

Dark pixels are proved inside (or, for Newton, a colour per proved root), pale ones proved outside, and the accent colour marks undecided pixels, which gather on the boundary. For Newton, give the coefficients highest first, separated by commas: 1, 0, 0, -1 is z³ − 1. Try the Mandelbrot set on Re −3/4, −1/2 and Im 0, 1/4, or the Julia set of c = −0.12 + 0.75i.
